## 🚀 Featured Projects

### 🛡️ LLM Prompt Firewall — AI-Powered Prompt Injection Detection Middleware `[🔨 Active Build — Day 5/21]`
> Engineering a production-grade security middleware layer that intercepts, scores, and blocks malicious prompts before they reach an LLM — **currently detecting prompt injection attempts across 25+ regex attack patterns with a 0.0–1.0 risk scoring engine** **as measured by blocking requests scoring ≥ 0.6 with HTTP 403 responses and structured latency-tracked logging per request** **by building a FastAPI middleware pipeline with Pydantic-validated schemas, typed error classes, and configurable risk thresholds wired to the Anthropic Claude API**. Roadmap includes ML-based semantic scoring with sentence-transformers + scikit-learn and a SQLite audit log — schema-first architecture ensures Day 6 JSONL logging maps directly to the future Day 11 database schema with zero migration overhead.

`FastAPI` `Python` `Anthropic Claude API` `Pydantic` `Prompt Injection Detection` `Risk Scoring Engine` `LLM Security` `Security Middleware` `AI/ML Security` `sentence-transformers` `scikit-learn`

---

### 🔐 AWS DevSecOps Security Pipeline
> Engineered an AI-powered CI/CD security pipeline that automatically scans every code push for vulnerabilities before reaching production — **accomplished preventing 33 security issues from reaching deployment** (7 code vulnerabilities + 26 infrastructure misconfigurations) **as measured by detections firing during GitHub Actions workflows with PR merge gates blocking all critical findings** **by implementing Semgrep SAST (586+ rules), Trufflehog secret scanning, and Checkov IaC validation with Claude API-generated security summaries**. Achieved sub-60-second scan completion time with Python automation and Terraform infrastructure-as-code for reproducible security gates across teams.

`GitHub Actions` `Semgrep` `Trufflehog` `Checkov` `Python` `Terraform` `AWS` `Claude API` `CI/CD Security` `DevSecOps` `Merge Gates` `IaC Scanning`

---

### 🍯 HoneyPot Lab — Cloud-Deployed SSH Honeypot with Real-Time Threat Intelligence
> Deployed a production-grade SSH/Telnet honeypot on AWS EC2 that captures real-world attacker behavior at scale — **accomplished fingerprinting 11 unique botnets and identifying a coordinated 4-IP DigitalOcean campaign** **as measured by analyzing 102 connection attempts from 24 unique attacker IPs across 9 countries with 26 successful logins** **by ingesting Cowrie honeypot logs via Filebeat into Elasticsearch and correlating HASSH signatures across Kibana threat detection workflows**. Built a Python threat intelligence pipeline enriching attacker IPs via MaxMind GeoIP, auto-generating MITRE ATT&CK mapped reports, and surfacing botnet patterns through AWS CloudWatch Logs Insights — shipping real-time alerts to Elastic SIEM for enterprise-grade attack visualization.

`AWS EC2` `Cowrie` `Elasticsearch` `Kibana` `Filebeat` `Python` `SIEM` `GeoIP Enrichment` `CloudWatch Logs Insights` `HASSH Fingerprinting` `Botnet Analysis` `MITRE ATT&CK` `Threat Intelligence`

### ☁️ Cloud IAM Attack Graph + AI Risk Analyzer

Built an automated IAM discovery pipeline using Python and boto3, developed a graph-based analysis engine to identify multi-hop attack paths, and delivered a full-stack dashboard with AI-generated attack narratives for interactive visualization of IAM misconfigurations and blast radius exposure.

`Python` `AWS IAM` `boto3` `FastAPI` `ReactFlow` `Graph Analysis` `Zero Trust` `Privilege Escalation Detection` `Cloud Security`
